# Automate Payment Workflows with the New Dwolla Node for n8n

We're excited to announce the release of our latest community node for n8n: the Dwolla integration! At Velocity BPA, we're committed to expanding the n8n ecosystem with powerful integrations that solve real business challenges.

## The Payment Automation Challenge

Processing payments, managing KYC compliance, and handling mass payouts traditionally requires extensive development work and complex API integrations. For businesses using n8n to automate their workflows, the inability to natively integrate with modern payment infrastructure has been a significant gap.

## Introducing n8n-nodes-dwolla

The Dwolla node brings enterprise-grade payment capabilities directly into your n8n workflows. Dwolla is a leading platform for ACH transfers, Same-Day ACH, Real-Time Payments (RTP), and compliance management. Now you can orchestrate these powerful features without writing a single line of code.

## Key Features

**ACH & Real-Time Payments**: Initiate standard ACH transfers, Same-Day ACH for faster processing, or leverage Real-Time Payments for instant transfers—all from within your n8n workflows.

**KYC Management**: Automate customer verification processes with built-in KYC capabilities, ensuring compliance while maintaining smooth user onboarding.

**Mass Payments**: Process bulk payments efficiently, perfect for payroll, vendor payments, or marketplace disbursements.

**Webhook Integration**: React to payment events in real-time by integrating Dwolla webhooks into your automation workflows.

## Getting Started

Installing the Dwolla node is straightforward. In your n8n instance, simply run:


npm install n8n-nodes-dwolla


After installation, restart n8n, and you'll find the Dwolla node available in your node palette.

## Use Cases

Imagine automating your entire payment workflow: receiving payment requests via form submissions, performing KYC checks, initiating transfers, and sending confirmation emails—all in a single n8n workflow. The possibilities are endless for fintech platforms, marketplaces, HR systems, and any business handling digital payments.
